What Gets Synced

✓ Windows PCs & Laptops
Synced into the Computers table. Matched by serial number or Intune device ID.
✓ Compliance Status
Compliance state (compliant/noncompliant/unknown) and last check-in time are updated on each sync.
— Mobile / iOS / Android
Skipped for now. Only Windows and macOS devices are imported.
New devices not found in inventory are created with status "Synced from Intune" so they're visible but clearly marked as pending review. Existing records are updated in place — no data is deleted.
