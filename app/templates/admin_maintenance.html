How It Works

1. Announce
You type a message and click Announce. An orange banner immediately appears at the top of every page for all logged-in users.
2. Countdown
If you set a countdown, the banner shows "Restarting in X minutes" and updates every minute until it reaches zero.
3. Restart
When the server restarts, the banner automatically disappears (state is in-memory). Users see the app come back normally.
Force Reload
After deploying an update, use Force Reload to push all active browsers to refresh immediately so everyone gets the latest version.
